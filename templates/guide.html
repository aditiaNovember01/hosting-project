Mulai Dari Sini
Sebagai user hosting, Anda hanya perlu fokus pada code project Anda. Urusan domain, database, dan web server sudah diatur oleh Admin.
Alur kerja umum:
  1. Clone project dari GitHub ke folder hosting Anda via Terminal
  2. Buat file .env berdasarkan .env.example
  3. Isi konfigurasi database yang diberikan Admin
  4. Jalankan composer install atau npm install
  5. Jalankan migration jika perlu
  6. Project langsung bisa diakses via domain yang diberikan Admin
Hubungi Admin untuk: setup domain, buat database baru, atau install software tambahan.
Git & GitHub
Clone project baru:
git clone https://github.com/username/nama-repo.git
Clone ke folder tertentu:
git clone https://github.com/username/nama-repo.git nama-folder
Update project (pull):
cd nama-repo
git pull origin main
Cek status perubahan:
git status
git log --oneline -5
Untuk repo private, gunakan Personal Access Token GitHub sebagai password saat clone.
Laravel / PHP
Setup project Laravel baru:
# 1. Clone project
git clone https://github.com/user/laravel-app.git
cd laravel-app

# 2. Install dependencies
composer install

# 3. Buat file .env
cp .env.example .env

# 4. Generate app key
php artisan key:generate

# 5. Edit .env (isi DB_* dari Admin)
nano .env

# 6. Jalankan migration
php artisan migrate

# 7. Jalankan seeder (opsional)
php artisan db:seed
Command artisan yang sering dipakai:
php artisan migrate          # Jalankan migration
php artisan migrate:fresh    # Reset & jalankan ulang migration
php artisan db:seed          # Jalankan seeder
php artisan cache:clear      # Bersihkan cache
php artisan config:clear     # Bersihkan config cache
php artisan storage:link     # Buat symlink storage
php artisan make:model Nama  # Buat model baru
php artisan route:list       # Lihat semua route
Jangan jalankan php artisan serve — web server sudah diatur Admin via Nginx.
Node.js / NPM
Setup project Node.js:
# Install dependencies
npm install

# Build untuk production
npm run build

# Atau jika pakai yarn
yarn install
yarn build
Untuk project Next.js / React:
npm install
npm run build
# File hasil build ada di folder 'out' atau '.next'
Jangan jalankan npm run dev atau node server.js secara langsung. Hubungi Admin untuk setup Node.js sebagai service.
Python
Setup project Python/Flask/Django:
# Install dependencies
pip3 install -r requirements.txt

# Buat .env
cp .env.example .env
nano .env

# Untuk Django - jalankan migration
python3 manage.py migrate
python3 manage.py collectstatic
Jangan jalankan python3 app.py atau flask run langsung. Hubungi Admin untuk setup Python app sebagai service.
Konfigurasi File .env

File .env berisi konfigurasi sensitif project Anda. Admin akan memberikan data database yang perlu diisi.

Contoh .env Laravel:
APP_NAME="Nama Aplikasi"
APP_ENV=production
APP_KEY=         # diisi setelah php artisan key:generate
APP_DEBUG=false
APP_URL=https://domain-anda.com

DB_CONNECTION=mysql
DB_HOST=localhost
DB_PORT=3306
DB_DATABASE=nama_database    # dari Admin
DB_USERNAME=nama_user_db     # dari Admin
DB_PASSWORD=password_db      # dari Admin
Edit .env via terminal:
nano .env
Jangan pernah commit file .env ke GitHub! Pastikan .env ada di .gitignore.
